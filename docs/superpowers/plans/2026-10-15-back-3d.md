# Back Exercises in 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 3D pull-up (32), barbell bent-over row (33) and seated cable row (34) as a new 3D Back group, playable without baked clips, with old library ids `L0027`/`L0861` carried over to them.

**Architecture:** Body poses for 32–34 go in `dist/motion-body.js` (ids ≥ 20 already route there). `dist/athlete.js` skips the mixer when no `Exercise_<id>` clip exists, so `applyRigPose` alone poses the body. `dist/scene.js` builds the equipment and seats it at the real grips each frame. `dist/catalog.js` gains aliases so saved data and links for the replaced library entries resolve to the new 3D ids.

**Tech Stack:** Vanilla ES modules in `dist/`, Three.js r185 (vendored), `node --test`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-15-back-3d-design.md`

## Global Constraints

- Ids: pull-up `32`, bent-over row `33`, seated cable row `34`; 3D group key `back`; `groups.back=[32,33,34]`.
- Aliases: `L0027→33`, `L0861→34`; duplicates added: `"0652":32`, `"0027":33`, `"0861":34`; `0027`, `0861` removed from `include`; library becomes 135 entries.
- `bakedIds` = the 30 ids with clips in `athlete.glb` (current `allIds`); `allIds` = 33.
- Do not re-export `athlete.glb`. Do not change the poses or clips of the existing 30 exercises.
- Muscles button disabled for `back` with legend text `Back overlay not available`.
- Posture checks run on the real skinned mesh (`tests/posture.test.mjs` helpers: `studio()`, `clearance`, region lists).

## Review Focus

- Saved data or a backup holding `L0027`/`L0861` must load with those entries turned into 33/34, not dropped. → Task 5 test.
- Opening a new 3D exercise straight from a link (`#exercise/32`) before any other exercise must render, not throw on the missing clip. → Task 1 test + Task 6 browser step.
- Switching from a baked exercise to 32–34 and back must not leave the previous clip playing over the live pose (mixer stopped). → Task 1 test.
- The Muscles toggle left on while moving from a chest exercise to a back one must not keep the chest lit or leave the button pressed. → Task 2 browser step.
- Workout and Stats with a 3D back exercise logged must count under Back. → Task 5 test.
